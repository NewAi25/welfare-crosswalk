# Audit log

One row per audited version. The push gate accepts a push when this file has a PASS row for the commit being pushed, or for its parent when the pushed commit changes nothing but this file. A row is written only after the research-auditor agent ([.claude/agents/research-auditor.md](../.claude/agents/research-auditor.md)) has returned AUDIT: PASS on the changes not yet pushed, and after three mechanical checks have passed: `python 3_code/check_tables.py`, `python 3_code/check_sources.py --local` and `python 3_code/build_output.py --check`. The push gate, [3_code/hooks/pre-push](../3_code/hooks/pre-push), runs the same three checks again and refuses a push unless the committed copy of this file has a PASS row for the commit being pushed, or for its parent when the commit being pushed changes nothing but this file. It is turned on once per copy with `git config core.hooksPath 3_code/hooks`. Rows are never edited, so older rows use the file names of their day (definitions for what is now rules.md, scripts/ for what is now 3_code/); the decision_log.md entry of 2 October 2026 on the reorganisation gives the old and new names. The predecessor repository's three audits are in its own log.
